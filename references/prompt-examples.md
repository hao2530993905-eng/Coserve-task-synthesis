# 提示词示例

以下均是你扮演不同用户时向 CoServe 提出的初次问题或任务请求，用于校准用户口吻。示例不代表固定题库或附件已经准备好。

| 使用者与场景 | 任务栏示例 | 多轮预判 |
| --- | --- | --- |
| 新用户，明确尺寸建模 | 帮我画个垫圈，外径 40，里面的孔 20，厚 3 毫米。 | 否 |
| 新用户，外壳设计 | 想给这块电路板做个外壳，能拆开，接口露在外面。我把板子的模型发你了，你帮我设计一下。 | 是，可能需要尺寸与方案确认 |
| 熟练用户，局部修改 | 这块板右边两个孔改成沿长边的长圆槽，总长 14、宽 6.6 毫米，原孔心作为槽中心，左边两个孔不动。 | 否 |
| 专业用户，配合检查 | 轴径范围 19.980～19.993 mm，孔径范围 20.000～20.021 mm。核一下极限直径间隙，再和附件模型的名义间隙对一下。 | 否 |
| 专业用户，设计取舍 | 这个底座要减重，A 面和三个定位孔周边 8 mm 不能动。先帮我看看可去料的位置，加工方便优先，减重目标可以看方案再定。 | 是，用户参与方案取舍 |
| 专业用户，结构分析 | 对附件加筋圆柱做仅轴压、仅外压和两者同时作用三组线性静力，载荷按表，网格和约束保持一致。比较同一位置的位移与应力分量是否满足叠加关系。 | 否，计算轮数不等于用户消息轮数 |
| 新用户，图像重建 | 能照这两张图帮我做个模型吗？中间的孔想改成 12 毫米。 | 是，真实图片可能仍缺尺度或孔深 |
| 专业用户，工程图重建 | 按这套剖视图恢复台阶孔，孔径、深度用标注值，底面 A 为基准。背面那个凹口也保留，做好给我 STEP。 | 视图信息充分时可标否 |

同一条任务无需覆盖全部信息。新用户可以准确提供尺寸，专业用户也可能缺少关键参数；依据本题实际输入判断是否需要澄清。

避免把任务写成“首轮先展示，第二轮用户改孔径，第三轮取消凸台”。CSV 中只保留当前用户提出的目标，后续修改随真实反馈发生。

不要把所有专业题都写成完整计算规范。与当前目标无关的坐标变换矩阵、日志、文件哈希、误差表和工具调用方式，留给执行或评测设计；用户确有这些需求时再写入。
